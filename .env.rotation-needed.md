## Procédure de rotation

### OPENCLAW_GATEWAY_TOKEN

Générer : `python3 -c "import secrets; print(secrets.token_hex(32))"`
Mettre à jour dans : .env + openclaw.json (si hardcodé)

### OPENROUTER_API_KEY

Portail : https://openrouter.ai/keys
Action : Révoquer l'ancienne clé → Créer nouvelle clé

### GEMINI_API_KEY

Portail : https://aistudio.google.com/apikey
Action : Supprimer l'ancienne → Créer nouvelle

### MISTRAL_API_KEY

Portail : https://console.mistral.ai/api-keys/
Action : Révoquer → Régénérer

### DEEPSEEK_API_KEY

Note : DeepSeek retiré de la config Albert (RGPD Art. 44)
Action : Révoquer sur https://platform.deepseek.com/api_keys

### MOONSHOT_API_KEY

Portail : https://platform.moonshot.cn/console/api-keys
Action : Révoquer → Régénérer

### GLM_API_KEY

Portail : https://open.bigmodel.cn/usercenter/apikeys
Action : Révoquer → Régénérer

### ZAI_API_KEY

Action : Identifier le portail source et révoquer

### GROQ_API_KEY

Portail : https://console.groq.com/keys
Action : Révoquer → Créer nouvelle clé

### GITHUB_TOKEN

Portail : https://github.com/settings/tokens
Action : Révoquer le token → Régénérer avec les scopes minimaux nécessaires

### TELEGRAM_BOT_TOKEN

Portail : Parler à @BotFather sur Telegram
Commande : /revoke → /token (pour obtenir un nouveau token)

### DATALAKE_DB_READER_URL

Action : Changer le mot de passe du compte reader dans la base de données
Format attendu : postgresql://user:NEW_PASSWORD@host:port/dbname
